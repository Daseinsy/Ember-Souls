# 1 ダスク・トレイン

駅は人でごった返しており、ほとんどの人が召使いのように立ち尽くし、列車の到着を待っていた。

遠くの地平線に列車が現れた。車体全体がガラスのような光沢を放っていた。夕日の光の中で、それはまるで黄金の翼へと溶け込み、ゆっくりと空から舞い降りてくるように見えた。

冷たい合成音声が放送された。「天国列車２号がまもなく駅に到着します。乗客の皆様は安全にご注意ください。」

黒と白の制服を着た超能力者たちは、超能力人形たちに指示を出し、プラットフォーム付近にまだ残っている者たちを追い払った。

林静は人混みの中に立ち、短い黒髪をなびかせながら、祖母から手作りの煎餅（国風クレープ）を受け取っていた。林静は実際にはお腹が空いていなかったが、それでも一口食べた。ネギの香りと燻製の風味が混ざった、おなじみの味が口の中で広がり、彼の目は少し潤んだ。

祖母は継ぎ当てだらけの古い赤いベルベットのバッグを持ち歩き、彼の毎日の必需品を列挙しながら、「自分の体を大切にして、もっと水を飲みなさい」と小言を言っていた。

「シャオ・リンはとても才能のある子だ」と、周囲の親戚たちはいつも口々に言い、期待に満ちた目で彼を見つめていた。「彼はきっと強力な霊的修練者になるだろう。」

「大学に進学できる子供は本当に少ないのよ」と叔母がおしゃべりに言った。「たとえ一族全員の資金を出し合ってでも、息子の教育を支援するためにできる限りのことをするつもりよ。」

「もしシャオリンが将来、強力な霊的修練者になったとしても、決して三番目の叔父のことを忘れないでください。」

彼は頷きながら、真剣に荷造りをしているふりをして話を聞いていた。彼はほとんどの偽りや仮面を見抜く能力を持っており、世界は常に騒がしいので、彼はただその騒音だけを感じていた。

列車がまさに着陸しようとしたその時、ぼろぼろの服を着た乱れた人影が群衆の中から飛び出し、まるで翼を折られた鳥のようによろめきながら線路に向かって倒れ込んだ。周囲の人々は息を呑み、急いで道を譲った。

列車は容赦なくその上を通過し、強烈な衝撃波が血の霧となって爆発したが、頑丈なガラス製の車体は無傷のままで、列車は揺れることもなく、プラットフォーム上で静かに停止した。

人間の霊媒師の管理者が、何かをぶつぶつと呟きながら現場に現れた。彼が手を振ると、霊的な物が入った袋が飛び出した。袋からは正確かつ抗いがたい吸引力が発せられ、線路上のあらゆる肉片や死骸を袋の中に引き込んだ。

プラットフォームにいた人々は、この光景を無関心に見守っていた。哀れみや苦痛の表情を見せたのは、ごく少数の者だけだった。

乗務員は各車両に立ち、身分証明書の確認に備えていた。

林静は超能力人形に迎えられた。人形は学院から支給された彼の制服、つまり彼の登録番号が記された制服を一瞥し、それから無表情な顔に人間のような敬意を表した。

ここは霊力が修練の基盤であり、強力な霊力修練者は山や海を動かす力さえ持つ世界だ。以前は粗末な麻の服を着て街を歩いていた彼は、無関心や軽蔑の目で見られていた。しかし今、この制服を着ると、すべてが変わった。

リン・ジンは最後に一度振り返り、家族に手を振って別れを告げた。

彼に見えたのは、祖母の優しい笑顔と、曇りがかった瞳に宿る無垢な光だけだった。

列車が動き出すと、林静は窓際に座り、ガラス越しに後ろを振り返った。祖母は相変わらず見慣れた赤いキャンバス地のバッグを手に持ち、静かにプラットフォームに立って彼を見守っていた。列車が徐々に上昇するにつれ、祖母の姿は次第にぼやけ、次第に不明瞭な黒い点となり、ついにはその点さえも消えてしまった。

彼が幼い頃に母親が亡くなった。その後、父親も別の都市へ働きに出てしまい、いくらかの退職金を残していった。彼を頼れるのは祖父母だけだった。その後、祖父も亡くなった。彼は何度も死を目の当たりにし、それ以来、死そのものを恐れるようになった。

「まさか、これが私たちが会う最後になるなんてこと？」

「いいえ、私たちは必ずまた会えるでしょう。」

林静は独り言を呟き、椅子に深く腰掛けそうになったが、背筋を伸ばした。

馬車は人でぎっしり詰まっており、ほとんどの人が粗末な麻の服を着ていた。時折、誰かが彼に目を向け、うつむき、かつて彼が重要な人物たちを見つめた時と同じように、複雑で言葉にならない表情を浮かべた。

これらの視線は彼を過去から切り離し、まるで別人になったかのような感覚を与えた。

しかし、彼は幸せを感じていなかった。

彼はかつて本で読んだ一文を思い出した。「貧しい時は自らの徳を磨き、成功した時は天下すべての人々に恩恵をもたらすべきである」。しかし、貧しい者は常に不安を抱えているため、ほとんどの人はそうすることができない。ましてや、高い地位にある者が、他の種の苦しみを理解できるはずがない。

さらに、彼は貧しくもなく、成功者でもない。どちらにも属さず、中途半端な状態に陥っているのだ。

彼の思考は潮のように押し寄せたが、心の奥底には空虚感があった。

彼は自分が何者なのか、どこから来たのか、どこへ向かっているのかも分からなかった。何かが絶えず彼をある方向へ押し進めているようだったが、それが何なのかはっきりとは分からなかった。彼はまだ、最もふさわしい道、その道そのものに内在する救済の感覚を見つけていなかった。この世界に属する、最も愛すべき人々は、すでに空を横切るレーザー光線の中に消え去ってしまった。私たちには何が残されているのだろうか？

林静は時折、こうした奇妙な疑問について考えるが、すぐにそれを抑え込み、車の窓の外の景色を見上げる。

列車は人影のない空高く、光速で旅を続け、眼下の景色はどんどん小さくなっていった。

彼は生まれてこの方、これほど壮大な光景を見たことがなかった。遠くの村々や木々は、暗い黄金色の光の中でベールに包まれているように見え、まるで古の時代に残された水墨画のようだった。色とりどりの花々は虹色の光を放ち、風に舞い落ち、世界のこの上ない美しさが滝のように流れ落ちていた。

彼は気づかないうちに眠ってしまった。本当に疲れていたのだ。家で眠る勇気はほとんどなかった。ほんの少しうとうとしただけで、また井戸の夢を見てしまった。

彼はまるで深淵を歩いているかのようだったが、そのまま頭から井戸に飛び込み、羽のようにゆっくりと落ちていった。伝説によれば、冥界には無数の墓石があり、それぞれに詩が刻まれ、無数の物語が語られているという。冥界が本当にどこにあるのかは誰も知らない。伝説では、それは井戸の中にあり、誰もがそれを夢見る機会があると言われている。彼はそれが恐怖だと分かっていた。井戸の底から忍び寄る、言葉では言い表せない冷たさが。

林静は身震いしながら夢から覚めた。井戸の中で何を見たのかは覚えていなかったが、胸を締め付けるような悲しみと苦痛は鮮明に覚えていた。

彼の胸に激しい衝動が湧き上がった。まるで何かを掴み取りたいか、何かを叩き壊したいかのようだった。

しかし彼はこのことを誰にも話さなかった。なぜなら、彼は神の国が井戸が見えると主張する子供たちをどのように扱っているかを、自分の目で見ていたからだ。

ちょうどその時、彼はその少女を見かけた。

彼女は斜め向かいに座り、顔をベールで覆い隠していた。まるで他人に気づかれたくないかのようだった。しかし、澄んだ輝く瞳は見る者を魅了した。

彼女は長く、空のように真っ赤な髪をしていた。それは、夕暮れの最後の光が消えることなく輝き続けるような、燃えるような色だった。

林静は心臓がドキッと跳ね上がり、自嘲気味に微笑んだ。彼は自分が感傷的な人間であり、美しいものにすぐに気づいてしまう傾向があることを自覚していた。

しかし今回は違う。

彼を惹きつけたのは、彼女のぼんやりとした顔立ちではなく、彼女独特のオーラだった。まるで何かを感じ取ったかのようだった。どこかで彼女を見たことがあるような、いや、むしろ、親近感、まるで魂の伴侶のような感覚を覚えたのだ。

彼の呼吸は穏やかになり、リラックスし始めたが、同時に、彼の体はまるで執拗なレーダーのように、たとえ危険がなくても、周囲の潜在的な危険を必死に探していた。

車の窓の外では、空が暗くなり始めていた。

神の国の境界の向こうには永遠の夜、廃墟の上に広がる荒涼とした荒野が広がっている。しかし、神の国の中では昼間は薄明かりである。なぜ薄明かりなのか？それは、人工太陽が薄明かりの色しか表現できないから、あるいは、霊的なエネルギーを節約するために、最小限の光しか放出できないからである。

寺院の中では、様々な儀式を終えた後、執事たちが人工太陽への電力供給を徐々に遮断し始めた。空の光は次第に弱まり、提灯を持った夜警たちが通りを歩き回り、夜が近づいていることを人々に知らせた。夜間の巡回と執事たちが秩序を維持し、それまでははしゃいで遊んでいた子供たちは、「暗くなってきたよ」と家族に促され、慌てて家路についた。

ここは都市国家に過ぎないが、とてつもなく巨大で、移動には超能力列車が必要なほどだ。各家庭はそれぞれ専用の別荘を持っている。居住区は広大で、商業地区は主に指定された区域に集中している。

神々の王国は、生活に必要な最低限のものをすべて提供してくれる。働かなくても、誰もが生き延びることができる。なぜなら、この都市国家はほとんどの場合、それほど多くの人員を必要としないからだ。ほとんどの仕事は、霊的修行者が作った霊人形によって行われ、多くのことがもはや人間の介入を必要としない。一般市民の唯一の義務は、霊的なエネルギーから作られた霊石を毎月都市国家に納めることだけだ。

すべての人の身元が登録され、超能力によるコミュニケーションが至る所で行われている。まるで天の目が神々の王国全体を覆うかのようだ。

神界における最高位の職業は、当然ながら神殿に関わるものである。神界は広大であるため、神殿は様々な地域に建てられている。しかし、最も中心的な神殿は、まさに中心部に位置する神殿であり、そこから人工の太陽が昇る。周辺地域に近づくほど、守護は弱まり、光は弱まり、危険度も増す。集められた霊石はすべて神殿に運ばれ、そこで燃やされることで神界の安定が保たれると言われている。

一般の人々にとって、日光浴は超能力エネルギーを得る数少ない方法の一つである。

列車が神界に突入しようとした時、超能力による放送で「乗客の皆様、事前に身分証明書の確認にご準備ください」とアナウンスされた。

神々の王国は広大で、内側と外側はまるで二つの別世界のようだ。伝説によれば、そこは神々に近い場所であり、極めて厳格な管理下に置かれている。日が沈んだ後も、暗闇に潜む恐怖を追い払うために、予備の火が灯される。

しかし、ほとんどの人は入場する機会がなく、あるいは時折開催される祝賀行事の一般公開日にしか入場資格がない。

寺院では定期的に説法が行われており、各地に大規模な修行場が設けられている。一つの大きな修行場には数万人を収容できると言われている。秩序はどのように維持されているのか？もちろん、寺院から派遣された霊修者たちによって維持されている。強力な霊修者たちは、直接光の巨人に変身したり、配下の霊獣や鳥を使って全域を監視させたりすることができる。

霊力修練者の一団が馬車に乗り込んだ。彼らは恐ろしいオーラを放っていたが、それを巧みに隠していた。彼らの後ろには、サイオニック人形の集団と無数の霊獣が続いていた。

確認後、巨大な城門がゆっくりと開き、内城への入り口が現れた。

列車が駅に到着した。サイオニック放送が車内全体に響き渡った。少女は立ち上がり、人混みをかき分けて出口へと向かった。

林静はついて行かなかった。彼は少し大きめのリュックサックを背負って立ち上がり、群衆から大きく遅れて歩き出した。

林静は出口に向かって歩き、夜風が彼女の顔に吹きつけた。遠くには、光の巨人が静かに立っていた。これらの光の巨人は神々の王国中に点在し、静かな灯台のように地上を見守っていた。

彼は少女が去った方向をちらりと振り返った。

少女はもういないが、彼女の瞳に宿る澄み切った、それでいて深い光は、彼の記憶の中に今もなお残っている。

リュックサックは少し重かった。中には彼の荷物全てと、祖母からもらった冷たい煎餅果子（国の塩味クレープ）の袋が入っていた。

彼は深呼吸をして、暗闇の中へ足を踏み入れた。

彼はこれから何が待ち受けているのか分からなかったが、前に進まなければならないことは分かっていた。

あの押し寄せる人々の波のために、そして説明のつかない、不可解なすべてのもののために。
