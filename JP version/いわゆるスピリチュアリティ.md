#  いわゆるスピリチュアリティ

人の幸福と健康は、その人の精神性によって左右されると言われています。精神性が衰えると、最初は多くのことに興味を失い、喜びをもたらすものを必死に探し求めます。やがて、喜びを全く感じることができなくなり、感情の起伏さえも失い、動くことはできても既に死んでいるような状態になってしまうと言われています。伝説によると、人の精神性を直接操り、人を操り人形に変えてしまう禁断の書物が存在するそうです。
人が精神的に高ければ高いほど幸せになるというのは真実ではありません。言い伝えによると、これは精神性のある側面と関係があると言われていますが、学者たちは未だにその秘密を解明できていません。
