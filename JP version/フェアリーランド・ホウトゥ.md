#  フェアリーランド・ホウトゥ

伝説によれば、緑豊かな森が存在し、その空気は清々しく生命に満ち溢れ、まさに地上に隠された楽園だという。その場所を知る者は誰もいないが、偶然そこにたどり着いた者もいる。しかし実際には、この楽園の静寂は孤立という代償の上に成り立っている。自給自足で平和に暮らし、一見完璧に見える。だが、本質的に持続不可能な状態にある。外部からの侵略は孤立を防ぐことはできず、内部の葛藤は最終的に侵略へと繋がるだろう。人間の心に欲望が存在する限り、真に純粋なエデンは存在し得ないのだ。

ここは、ラグナロクによって孤児となった生き物たちが住む、トラウマによってほぼ破壊された土地であり、彼らはもはや人間や外界を信用していない。おそらくその平和的な性質ゆえに、エルフと精霊獣は数えきれないほど長い間平和に共存し、この地は楽園のように見える。しかし、これらの不死の存在は、戦争で同族が引き裂かれるのを目撃し、消えない傷跡を残したため、世界から孤立した。彼らはまた、人間は原罪を背負って生まれてくると信じており、感受性の強い存在である彼らは常にその罪を人間の中に見ることができるため、人間を受け入れることを拒否している。テクノロジーが人間と遭遇した場合、最善の策は、人間が自然な寿命を終えるまで永遠に生きさせ、人間の子孫を信用しないため、繁殖権を奪うことである。エルフが人間と出会い、その使命を察知した場合、彼らは人間の目隠しをして感覚を奪い、遠ざけ、秘密の協定を結び、さらに安全のために別の場所へ移送する。

この世界にも輪廻転生の物語は存在するが、それは異世界への転生ではない。むしろ、海を越え、時空を超えた転生なのだ。元々別の都市国家にいた人物が、海の向こうの遥か彼方の世界に放り込まれることもある。そこでは時間の流れさえも異なっている。
