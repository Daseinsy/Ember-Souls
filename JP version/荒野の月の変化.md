#  荒野の月の変化

まるで固まったインクのように、暗闇が四方八方から押し寄せてきた。

荒れ地には道はなく、あるのは小石と枯れた草の根だけだった。着地するたびに鈍い音が響き、林静の骨が痛んだ。彼女はガンマの背中に横たわり、顔をざらざらした白い毛皮に埋め、喉には錆の味がした。

風は背後から迫ってくる追跡者の音を断片に切り裂き、断続的に彼らの元へと送り返した。

「林静、走るのをやめろ！お前が召喚した獣はもう走れないだろう？」

「たかが白い犬じゃないか。よくもまあ、こんな奥深い荒野に足を踏み入れたものだ。」

鋭い笑い声が風に乗って聞こえた。林静は振り返らなかったが、遠くで飢えた蛍の群れのように、背後でちらつくサイキックエネルギーの粒を感じ取った。彼女は足をぎゅっと閉じ、無意識のうちにガンマの首筋の髪を引っ張った。冷たい汗と血で固まった髪は、冷たく彼女の手のひらに張り付いた。

ガンマは音を立てなかった。ただ走り続けた。

林静はこの静寂に慣れ親しんでいた。子猫の頃からずっと静かで、丸い雪玉のように彼女の霊陣の中央で丸まり、目はほとんど開かず、濡れた鼻を彼女の指にこすりつけていた。その後、腰の高さほどの大きな白い犬に成長した――いや、彼女はいつもそれを犬だと思っていた。霊獣の血統には白い犬はいない。突然変異した雪のマスティフだと言う者もいれば、霊獣ですらないと言う者もいた。ガンマは決して反論せず、ただ彼女の足元をついていき、ふさふさした尻尾で地面を掃くだけだった。他の霊獣が襲いかかってきても、ただ横に避けて腹を彼女の足に押し付け、決して反撃しなかった。

そのため、リン・ジンはこれまで、他の可能性が存在するかもしれないとは全く考えていなかった。

突然、背後からヒューッという音が聞こえた。林静は思わず下を見ると、青白い霊刃が彼女の後頭部をかすめ、数本の髪の毛を切り落とした。焦げた匂いが辺りに充満した。

「走れ！走り続けろ！精霊獣すら守れないクズ野郎がどこまで逃げられるか見てみたい！」

追跡者の声が近づいてきた。林静は、まるで野生の蜂の群れのように、サイオニックエネルギーの羽音と混じり合った足音を聞いた。誰かが横から彼らに近づいた。背が高く痩せた男で、渦巻く風のサイオニックエネルギーの球を手に持ち、青い光が顔の半分を照らし、歪んだ笑みを浮かべていた。

「リン・ジン、その物を渡せ。さもないと、お前みたいな白犬野郎は今夜、荒野で腐肉の山になるぞ。」

彼が話している間に、風の精霊は既に彼の手から離れていた。ガンマは急旋回し、リン・ジンを横に投げ飛ばし、危うく彼女を転倒させそうになった。しかし、風の刃はガンマの左後ろ足をかすめた。ガンマの喉からかすかなうめき声が漏れ、彼女はよろめき、速度が急に落ちた。

追っ手がさらに迫ってきた。暗闇の中で青、赤、白の光がちらつき、まるで絞首縄がゆっくりと締め付けられていくようだった。林静はついに彼らの姿をはっきりと捉えた。5人の人物が、襟に獰猛な獣の模様が刺繍されたお揃いの灰色のローブを身にまとっていた。リーダーは禿げ頭で、不気味な眼差しをしていた。彼は超能力を一切使わず、ただ両手を後ろに組んで立ち、まるで既に終わった狩りを傍観しているかのようだった。

「林静」と、禿げた男は低い声で言ったが、その声は風を切り裂くほど明瞭だった。「お前は半夜も荒野を犬に乗って横断してきたんだぞ。疲れていないのか？」

周囲から低い笑い声が聞こえた。

リン・ジンは息を切らしながらガンマの背中から滑り落ちた。バランスを崩し、膝が崩れて地面に半膝をついた。ガンマはすぐに振り返り、体をガンマの体で彼女を庇った。左後ろ足からは血が流れ、濃い赤色の液体が白い毛皮を伝って足先に溜まっていた。耳は後ろに倒れ、尻尾は折り畳まれるどころか垂れ下がり、喉からは低い唸り声が漏れていた。

「ガンマ…」林静は手を伸ばしてその温かい体に触れた。それは震えていた。

禿げ頭の男は一歩前に進み出て、まるで商品を品定めするかのようにガンマに視線を向けた。「この霊獣は……悪くない。間違った主人に仕えていたのが残念だ。その品物を渡せば、命は助けてやろう。」

「私のせいじゃないわ」とリン・ジンは言った。彼女の声は、まるでサンドペーパーで喉をこすられているかのように、かすれていた。

「最後まで頑固だな。」禿げ頭の男はため息をつき、隣にいる人物にウインクした。背が高く痩せた男はすぐに手を上げ、風の霊気が再び凝縮し、以前よりも明るく速く、まるで青緑色の刃のようだった。

「もう一度聞くが、その品物はどこにあるんだ？」

リン・ジンは何も答えず、ただガンマの首に抱きついた。その時、彼女の額はガンマの首に触れ、まるで地下河川のように、その血管を流れる血潮を感じた。ガンマは頭を回し、鼻先で彼女の耳をこすった。暗闇の中で、その深い茶色の瞳は、これまで幾度となく見てきた夜と同じように、静かで従順な様子で彼女を見つめていた。

しかし次の瞬間、風の羽根が到着した。

林静は光を見た。青みがかった白い光が、まるで月の薄いかけらのように、彼らに向かって突き刺さった。彼女は目を閉じ、ガンマの毛皮に顔を埋めた。

すると、彼女はパキッという音を聞いた。

彼女が殴られたわけではない。彼女の体内で何かが粉々に砕け散ったのだ。

その音は言葉では言い表せないほどだった。まるで彼女の魂の奥底でガラスの壁が砕け散り、そこから精神エネルギーがほとばしり出たかのようだった。彼女の心臓は、見えない手に掴まれたかのように締め付けられ、そして突然解放された。血が手足に流れ込み、指先がピリピリと痺れた。彼女は、自分のものではない灼熱感が、胸から腕、そしてガンマの肌へと広がっていくのを感じた。

ガンマは頭を上げ、低い遠吠えを上げた。

その遠吠えは、まるで古代の荒野の奥底から聞こえてくるようで、地面をわずかに揺らしていた。林静が目を開けると、ガンマの体が光り輝いていた。最初は淡い銀白色だったが、次第に月光が固まったかのように輝きを増していった。光の中で骨は変形し、伸び、肩甲骨の筋肉は激しく蠢いていた。林静はガンマが死んでしまうのではないかと危惧したが、そのすすり泣きは次第に別の音へと変化し、まるで眠れる巨人が寝返りを打つような、深く荘厳な音になった。

「一体何が起こっているんだ…」背が高く痩せた男は二歩後ずさった。風の刃は既に彼の手から離れていたが、目に見えない何らかの力によって空中で粉々に砕け散り、青い光の粒となって消えていった。

ハゲ頭の男の表情が変わった。初めて感情を露わにし、「くだらないことを言うのはやめろ、一緒に攻撃しろ！」と唸った。

5本の霊的なエネルギーの光線が同時に輝き、あらゆる方向から彼らに向かって猛スピードで迫ってきた。

ガンマは突然背中を弓なりに反らせた。リン・ジンは軽い力で持ち上げられ、再びガンマの背中に着地した。今度は、ガンマの体が以前よりも大きくなり、筋肉が鋳鉄のように固くなっているのを感じた。ガンマの四本の足は土に深く食い込み、力強い推進力で地面を蹴った。

轟音とともに、巨大な翼が肩甲骨から広がった。雪のように真っ白な翼は、一枚一枚銀色の光を放ちながら輝いていた。翼が展開した瞬間、発生した強風が最も近い敵を地面に叩きつけた。ガンマは空高く舞い上がり、足元の暗い荒野は急速に縮小していった。

いつのことかは不明だが、夜空に満月が現れた。

月は異常に大きく、縁は不気味な暗赤色に染まり、まるで半開きの目のように、荒涼とした平原の上に冷たく浮かんでいた。月光は白ではなく、銀赤色で、薄い霧のように静かに降り注いでいた。

リン・ジンはガンマの背中に横たわり、月を見上げていた。彼女はこれまでこんな月を見たことがなかった。月光がガンマの翼に降り注ぎ、羽一枚一枚がまるで刃のように輝いていた。

ガンマが急降下してきた。

あまりにも速かったので、林静はただその毛皮にしがみつき、目を閉じたり開けたりすることしかできなかった。ガンマが口を開けると、月光が凝縮して銀赤色の球体となり、咆哮とともに吐き出された。球体は爆発することなく荒野に落下し、水面に波紋が広がるように、静かな衝撃波だけが瞬時に広がった。月光は灰色のローブを着た男たちに降り注ぎ、無数の小さな刃のように肉と骨を切り裂いた。彼らの叫び声は、聞こえる前に銀赤色の光に飲み込まれてしまった。

荒れ地は瞬時に静まり返った。

聞こえるのは風の音とガンマの荒い息遣いだけだった。

林静は下を見下ろした。地面の草や石は、まるで巨大な鋤で耕されたかのようにひっくり返され、深い溝が刻まれていた。灰色の衣をまとった男たちは姿を消し、岩の割れ目に死んだ蝶のように、焼け焦げた衣服の裾だけが残されていた。

ガンマはゆっくりと地面に降り立った。翼は折りたたまれ、体にぴったりと沿ったが、姿を消したわけではなかった。大きさも元に戻らず、馬よりも背の高い巨大な白い狼のままだった。ガンマは振り返り、鼻先でリン・ジンの手にそっと触れた。

林静は地面にひざまずき、ぼんやりとそれを見つめていた。背後から月光が差し込み、白い毛皮の縁を銀色に染めていた。その目はもはや優しい濃い茶色ではなく、溶けた琥珀のように淡い金色に変わり、不気味な満月を映し出していた。

「ガンマ…」彼女はかすれた声で叫んだ。

ガンマは頭を下げ、いつものように濡れた鼻で彼女の頬をこすった。その息は温かく、荒野の乾いた風と月光の匂いを運んでいた。リン・ジンは何か言おうと口を開いたが、喉が何かに詰まったような感覚に襲われた。彼女はついに、自分がずっと白い犬だと思っていたこの犬が、実は夜空の下で翼を広げることができる狼だったのだと理解した。

月はまだ頭上に浮かび、静まり返った荒野を冷たく照らしていた。遠くの地平線には、かすかな灰色の色合いがすでに現れていた。リン・ジンはガンマの柔らかな首筋の髪に顔を埋め、その声は風に消えていくかのようにか細かった。

「家に帰ろう。」

ガンマは、かすかなすすり泣き、あるいは生まれたばかりの狼の遠吠えのように、静かに反応した。
