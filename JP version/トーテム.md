#  トーテム

最初の覚醒後、各人は心の中で自身のトーテムを視覚化することができる。トーテムは、神話的トーテム、伝説的トーテム、聖霊トーテム、不死のトーテム、天界のトーテムの5つのレベルに分けられる。トーテムのレベルは固定されておらず、実践者が成長し、様々な経験を積むにつれて、トーテム自体が質的に変化する可能性がある。トーテムの力を活性化すると、実践者の額にそれに対応するトーテムの印が現れる。これは顕現した力の証であり、アイデンティティの証明である。

各人は、自身の経験と精神性に基づいて、独自の「称号」を培うことができる。称号を持つことができるのは、一定の修練レベルに達した者のみであり、そのような修練者は称号を持つ修練者と呼ばれる。称号は自由に隠すことができるが、特定の霊的なトーテムは修練レベルの障壁を突破し、隠された称号を直接明らかにすることができる。これが霊的なトーテムの貴重さであり、大国がそのような人材を競って獲得しようとする理由である。

個人のトーテムの他に、国家も国家トーテムを所有している。いくつかの主要な連邦はそれぞれ独自のトーテムを所有しており、青龍、猛虎、炎鳳凰、呼吸亀などがある。国家トーテムは抽象的な存在であり、個人の意志とは独立して存在し、むしろ何百万もの人々の集合的な意志を体現している。邪悪な精霊や魔獣が大規模な侵略を開始し、文明の存続を脅かすと、国家トーテムは人々の意志に従って世界に顕現する。その時、国内のすべての修練者のトーテムは彼らの体に痕跡を残し、これらの痕跡の数とランクは国家トーテムの強さに直接影響する。したがって、絶滅の危機に瀕したトーテム、特にかつては栄光があったが今は後継者がいない古代のトーテムを保護することは、重要な公共サービスとなっている。トーテム保護協会（保護協会と呼ばれる）は、トーテムが鏡界に相応の存在を持たなければならないため、この仕事を専門としている。それらは無から生じることはできない。

トーテムのもう一つの日常的な用途は、移動手段である。巨大な動物の形をした石像が街の広場に立っている。旅人はその台座に手のひらを置き、静かに目的地を唱えると、トーテムが目覚める。あるものは空を舞う風の鳥に、あるものは土に潜る大地の竜に、またあるものは川に浮かぶクラゲのように触手をゆらゆらと揺らめく。注入されるマナが多いほど、トーテムの変身は洗練される。貴族のトーテムは6枚の翼を持つ黄金のロック鳥に変身できるが、スラム街のトーテムはかろうじて3本足の獣に変身するだけで、3歩ごとに休憩する必要がある。トーテムが人間の意志に反応する理由を説明できる者はいない。職人は模様に古代のルーン文字が含まれていると言い、司祭は石は世界の創造以前の骨からできていると言う。懐疑論者は密かにこう議論する。もしかしたらトーテムは実際には動いておらず、空間に対する私たちの認識が変わっただけなのかもしれない、と。
