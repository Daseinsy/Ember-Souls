#  寿命、悲劇、そして神格化

すべての生命体には限界がある。人間はせいぜい百年しか生きられず、至高の領域で最も強力な存在でさえ、数千年しか生きられない。老化の本質は、澄んだ水がゆっくりと泥に変わっていくように、精神が濁っていくことにある。修行者は絶えず霊力を吸収することで老化を遅らせ、寿命を延ばすことができるが、それも無限ではない。いつか、目に見えない壁にぶつかる日が来るだろう。

その壁の名前は「嘆き」です。

悲しみが降り注ぐにつれ、精神性は不可逆的な混沌へと陥っていく。意識は最も原始的な粒子へと砕け散り、肉体は生きていても魂は消滅してしまう。修行者にとって、これは死よりも恐ろしい。死には少なくとも行き先があるが、悲しみは完全な消滅を意味するからだ。中には、悲しみが訪れる前に自らの命を絶ち、星空に灰を撒くことで、せめて尊厳ある最期を迎えようとする力強い者もいる。

無限の寿命を持つのは神々だけだった。しかし、神々はラグナロクで滅び、世界には彼らの権威の断片だけが残された。こうした限界を超越しようと切望する存在には、二つの道しかない。

まず、神格化という概念がある。人々は、捉えどころのない神の権威に触れるために、すべてを賭ける。成功すれば神になるという希望が生まれ、失敗すれば破滅が待っている。

第二に、受容。千年の歳月を終え、安らかに死を迎えること。人生のあるべきサイクルを完結させること。

大多数の人々は後者を選ぶ。なぜなら、神格化の成功率はごくわずかだからだ。しかし、常に、不可能だと知りながらあえてそれを成し遂げようとする不本意な人々が存在する。彼らは愚か者でもあり、英雄でもある。

冥界は星の海とも呼ばれる。その名の通り、天空に広がる場所だ。星々は眠れる魂のきらめきである。伝説によると、かつてある強大な存在が、長い間ひたすら上空へと飛び続けた。まず、霊気がまだ漂い、浮島や空飛ぶ魔獣が時折棲む「人間界」を通過し、次に周囲が死のように静まり返り、風さえも止んだ「虚空界」へと昇り詰めた。さらに上昇を続け、「認識層」に到達すると、奇妙な現象が起こる。上空へと飛んでいるにもかかわらず、まるで空が鏡であるかのように、自分の姿に引きずり込まれ、地面へと落下していくのだ。その強大な存在は、やがて衣を翻し、顔色を死人のように青ざめさせながら、出発点である山頂へと戻った。それ以来、星の海へと飛び込もうとする者は誰もいなくなった。

深海には巨大な裂け目があり、それはラグナロクの際に堕ちた神の爪が残した傷跡だと言われている。この裂け目の下の深淵は、あらゆる生物にとって禁断の地であり、怪物たちが跋扈している。ムカデのように千本の足を持つ海の蛇、人間の顔を持つタコ、そして船団を丸ごと飲み込み、深海でゆっくりと消化する透明なクジラなどだ。こうして海は自然の障壁となり、漁師たちは祖先の呪文を唱えながら、岸辺近くでしか網を投げることができない。しかし、絶望的な状況に追い込まれた者たちが、小さなボートで裂け目へと足を踏み入れることがある。中には、その奥深くで光を見た者もいると言われている。それは怪物の燐光ではなく、心臓の鼓動のような、純粋でリズミカルな輝きだった。

精神エネルギーは、物質を構成する根源的な分子である。この事実は繰り返し熟考する必要がある。なぜなら、生命そのものを含め、あらゆるものが精神エネルギーの表現だからである。これを理解することは、この世界の最も深遠な法則を理解することに他ならない。
