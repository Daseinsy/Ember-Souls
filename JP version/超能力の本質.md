#  超能力の本質

精神エネルギーは、この世界のあらゆる物質を構成する根源的な分子である。天地万物、山や岩から肉体や血、風や雷から思考に至るまで、すべては精神エネルギーの様々な配置と凝縮に基づいている。精神エネルギーは形がなく、触れることもできないが、砂や土に染み込む水のように遍在する。

思考そのものが力の一形態である。この世界では、思考は物質に直接影響を与えることはできないが、思考自身と直接相互作用することはできる。人間の意図には何らかの媒体が必要であり、最も一般的な媒体は視線が届く目である。盲人は、行動、音、あるいはその他の知覚形態に頼って精神力を伝達する。吟遊詩人は精神力を音に変換し、リズムを通して物体に影響を与える。高度な実践者は、精神力によって物理法則を一時的に変化させることさえできるが、この変化の影響が広範かつ大きくなるほど、必要な難易度とエネルギーは指数関数的に増大する。

精神力を使うと霊的なエネルギーが消費され、それは睡眠によってのみ回復できる。過剰な消費は精神的疲労を引き起こし、軽度の場合は失神、重度の場合は霊的基盤に永久的な損傷を与える。したがって、最も強力な修行者でさえ概日リズムを守らなければならない。これは力とは何の関係もなく、人生における鉄則なのである。

天石頭の完全クロマトグラム
天石は霊気の強さに応じて異なる色を発する。これは修真界では認識されている検出方法だが、その具体的な原理は未だ解明されていない。色のスペクトルは白、灰色、赤、緑、青、紫、金、虹の8段階に分けられる。これらの8色は初心者から伝説級まで様々な段階に対応するが、厳密には直線的な関係ではなく、同じ色でもかなり広い範囲をカバーする場合があり、一部の天才の霊気の色はこの分類システムを完全に超越することもある。
しかし、領域というものは定量化したり、正確に定義したりすることはできない、ただ感じ取るしかないということを強調しておかなければならない。たとえ目の前に賢者が立っていたとしても、その賢者がどれほどの力を持っているのかを正確に判断することはできないかもしれない。

主人公の深紅と黒のオーラは、まさにそれを象徴している。それは単なる色彩ではなく、永遠の夜の漆黒と混ざり合った深紅の色であり、瞬時に深淵を想起させる。この色は歴史記録にほんの数回しか登場しておらず、いずれも時代の流れを変えるほどの重要な人物に対応している。天石が主人公を観察すると、激しく震え、安定したオーラではなく、心臓が激しく鼓動するような脈動を発する――まるで天石自身が恐怖に囚われているかのようだ。

精神エネルギーの単位は「マナ」と呼ばれ、これは測定単位であると同時に、この世界の共通通貨でもある。マナコインには微かな精神エネルギーが宿っており、その半透明の水晶を通して光が動いているのが見える。マナコインには二つの性質がある。市場で食料、衣服、住居、交通手段と交換できるだけでなく、修行者が直接吸収することで経絡を精錬し、修行力を高めることもできる。貧しい人々のマナコインは消えゆく炭火のようにかすかに光るが、富裕層の金庫に保管されているマナコインは山積みになっており、その精神エネルギーは空気そのものが帯電しているかのようだ。精神修行者の強さは、どれだけのマナを保有しているかに大きく左右される。マナは修行のための資源であると同時に、力そのものでもあるのだ。
精神エネルギーは数値で測定でき、一般的に0から1000までは初期段階、100万以上は支配段階とみなされます。それ以上の値は、人間がそのレベルに達したことがないため記録されておらず、神々の領域と考えられています。しかし、人間の限界をはるかに超える精神エネルギー値を示す物体も存在します。例えば、999.999999という精神エネルギー値を持つ物体は、通常、古代の神々や霊的な遺物と関連付けられており、その存在自体が修行者の常識を覆すものです。

隆起部の三層構造を理解する

ある修行者が星空へと飛び立とうと試みたところ、その経験から天空の階層構造の秘密が明らかになった。最下層は「人層」と呼ばれ、霊気がまだ存在し生命を支え、時折、浮島や飛翔する魔獣が点在する。その上は「虚空層」と呼ばれ、風さえも止み、生命の痕跡が一切ない死のような静寂が広がる。最上層は「認識層」と呼ばれ、上昇しているにもかかわらず、まるで空が巨大な鏡で、自分の姿が映し出されて引きずり下ろされているかのように、地面に向かって落下していく。その強大な修行者は、やがて出発点の山頂へと戻り、衣を翻し、顔は死人のように青ざめていた。そして、それ以来、彼は二度とその経験について語ることはなかった。認識層の存在は、この世界の空間が平坦ではなく、極めて複雑な位相構造を持っていることを示唆している。つまり、あなたが探査していると思っているものは、実際には世界そのものによって跳ね返されているのだ。

物理法則の絶対的な限界

この世界には細菌もウイルスも細胞の反乱も存在しない。傷ついた肌に日光が直接当たっても感染の心配はない。なぜなら、肉眼では見えない微生物が傷口で増殖することはないからだ。炎症や発熱といった言葉は意味をなさない。「ワクチン」や「抗生物質」のように、古代の書物の片隅にひっそりと存在し、学者たちは古代人のばかげた集団ヒステリーとして議論している。しかし、手足が折れれば耐え難い痛みが走り、体が不自由になればよろめく。病気から守ったからといって、大地が慈悲深いわけではない。捕食者の牙が腕に食い込んだとき、引き裂かれるような感覚は隠すことなく、真摯で原始的なものだ。

電気も燃料もなかった。夜の焚き火だけが唯一の暖源で、風車や水車が軋みながら回転し、石臼や織機を動かしていた。そのため空気は格別に清々しく、一息ごとに山の湧き水を飲むような爽快感があった。銃は発明されなかったが、伝説によれば「鋼鉄のエネルギーと交信できる」者がいたという。こうした夢想家は「鉄の召喚者」と呼ばれ、冷たい金属の奥深くには眠る魂が宿っており、適切な言葉で目覚めさせることができると信じていた。これは今では失われた歌、子供たちが眠りにつくときに歌い、自分の影が鎧をまとった巨人に変わる夢を見た子守唄である。

星間連邦の技術者たちは、物理法則の限界に遥か昔に到達していた。原子の存在は知っていたし、原子を分解する方法さえ知っていた。しかし、それら全ては極地の氷冠に封じ込められた黒い箱の中に永久に封印されていた。議長でさえ、その箱に近づくことを敢えてしなかった。黒い箱の中に何が入っているのか正確に知る者はいなかったが、全ての支配者たちは暗黙の了解に達していた。それは決して開けてはならないものだった。一度開いた扉は、二度と閉じることができないのだ。


サイオニック力はあくまでも短時間の爆発的なパワーを表すものであり、実際の戦闘力を直接測る指標として用いるべきではないことに注意が必要です。サイオニック値が非常に高い人は、実戦を理解していない修練者である可能性があり、平均的な値を持つ人は、戦闘技術や専門的な能力に長けている可能性があります。未熟な修練者は数値だけを見ますが、真の賢者は相手のオーラを観察し、オーラを通して相手の修練レベルを大まかに推測します。しかし、これはあくまで推測に過ぎません。確信が持てない場合は、戦闘を避けるのが賢明です。なぜなら、道ですれ違う人が、初心者レベルの修練者なのか、それとも支配者レベルの強力な達人なのか、決して分からないからです。
