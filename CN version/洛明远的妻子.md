# 洛明远的妻子

洛明元的妻子也是学院的一位教授，只不过是教音律的，她出身于根正苗红的上城区大家族，也是一位在梦界家喻户晓的明星。
但是，她容貌优美，嗓音清澈，从小锦衣玉食，被父母保护的很好，长大以后也是直接嫁给了洛明远这位冉冉升起的炙手可热的平民出生的新星，将其牢牢的绑定在了家族的战船上，婚后育有一个女儿，可以说是人生美满。可以说是治愈系人设，一生都没吃过什么苦。
她说话总是温声细语，没有什么架子，同学和同事们也都很喜欢她，至少在大多数人眼里她是无害的。这也意味着她对某些特定的苦难缺乏共情能力，倾诉者即使说了也会面对她那平静的神情，然后把话自个咽下去。
她对规则对不公没什么概念，在她眼里这个世界的规则从她出生起就是如此，她也从没有质疑过这套规则，因为她自己就是这个金字塔上层的那些既得利益者保护的很好的后代。
