# 荒野、迷境与井

荒野是现象界最令人望而生畏的地方。不是因为那里常年不见光明，也不是因为邪灵经常出没——而是因为那深不见底的死寂与神秘。你徘徊在那里，任何方向都没有，经常迷失方向困死在里面。最彻骨的，是那种空无一人的寂寥的孤独。大声呼喊也听不见任何回应，而能听到回应反而更令人彻骨——你不知道那是什么：是人，还是非人之物发出的呼应，或者是那草丛被风掠过的不知名的沙沙声。

荒野最危险的不是黑暗和邪灵，而是侵蚀灵的“哀”。在荒野中停留有时间限制，超过一定期限后，灵会被荒野同化，要么转换为邪灵，要么转换为魔兽。因此，进入荒野的探索者都必须携带计时器——不是用来记录时间，而是用来计算自己还剩多少“灵性额度”。一些老练的荒野猎人会每隔一段路就返回一次，像潜水者上浮换气一样，用城邦的薪火重置自己的灵性状态。

荒野上散落着辉煌文明的废墟。那些废墟是更早的文明留下的——有些建筑风格完全无法辨认，有些雕刻的文字没有任何后人能读懂。聚落形态各不相同：有的聚落已经完全废弃，只剩下风化的城墙；有的聚落被邪灵占据，成为新的巢穴；还有一些聚落表面有秩序，实际上是邪神设下的养殖场——人们居住在围墙内，以为自己是自由的，其实只是被圈养的牲口。少部分人能够从荒野聚落中跃迁到城邦里，但他们反过来压迫那些还在荒野挣扎的人，如同当年自己被压迫一样。

迷境是通往各个世界的大门。那些门隐藏在荒野深处或被迷雾笼罩的区域，没有人知道它们通向哪里。传说迷境的尽头存在着究极魔头——曾经有主宰境的大能进入迷境，再没有回来。因此各大帝国都将迷境标记为红色禁区，调派军队层层封锁。但总有人好奇，总有人觉得“或许自己会是例外”。那些人的结局通常只有一个：成为新的传说素材。

传说，灵性极其强大的孩子会梦到一口井。那口井无尽幽深，井水如镜面，但照出的轮廓永远是扭曲的。孩子在梦中站在井边，低头看见的不是自己的脸，而是一个陌生人的轮廓，或者无数个人影重叠在一起的模糊形态。这种梦会反复出现，有时伴随剧烈的头痛、幻听、幻视。那些孩子被称为“井之子”。

井到底是什么？无人知道确切答案。有人说是世界意识的裂缝，有人说是上古神明的遗骸，有人说是镜界与现象界的连接点。但有一个共识是共同的：一旦下了这口井，就没有归途。它就像命运本身——你只能站在边缘看，而不能跳下去。跳下去的人，要么成为疯子，要么成为圣人，要么成为无面者。

井的意象贯穿于这个世界的最深处。每一个邪灵都曾是亡者，每一块界碑上都刻着一个悲剧。哀伤，是因为见过太深太深的井。而井之子们恰恰是这个时代最有希望的存在——因为他们仍然能感受到那份跨越个体的、几乎是针对命运的哀伤。只要还有人梦见那口井，只要还有人在井边徘徊、凝视、追问，这个世界就没有彻底死去。

灵性从来都不会枯竭，它只是被痛苦消磨掉了。但灵就像那井水一样——只要大地仍然有生机，干旱之后总有重新冒出来的一天。
