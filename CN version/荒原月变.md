# 荒原月变

黑暗像凝固的墨，从四面八方压下来。

荒原上没有路，只有碎石和枯死的草根，每一次落地都沉重地一顿，震得林静骨头生疼。她伏在伽玛背上，脸埋进粗糙的白色长毛里，喉咙里全是铁锈味。

风把身后追兵的声音切成碎片，断断续续地送过来。

“林静——别跑了！你那个召唤兽，跑不动了吧？”

“一条白狗而已，也敢往荒原深处钻？”

尖利的笑在风里飘。林静没回头，但她能感觉到远处有灵能光点，像一群饥饿的萤火，忽明忽暗地缀在身后。她夹紧双腿，手指无意识地揪住伽玛颈后的毛。那毛发被冷汗和血粘成一绺一绺的，冰凉地贴着掌心。

伽玛没有发出声音。它只是跑。

林静熟悉这种沉默。小时候它也是沉默的，刚出生时像一团滚圆的雪球，缩在她的灵阵中央，连眼睛都睁不开，只会用湿漉漉的鼻尖蹭她的手指。后来它长大了，变成一只到人腰高的大白狗——不，她一直以为那是一条狗。灵兽谱系里没有白狗，有人说它是变异的雪獒，有人说它连灵兽都算不上。伽玛从不辩解，它只是跟在她脚边，尾巴蓬松地扫过地面。其他灵兽扑咬它的时候，它也只是侧身躲开，把肚皮贴到她腿后，从不还口。

所以直到这一刻，林静都没有想过，它会有别的可能。

一道破风声突然从背后劈来。林静下意识低头，一道青白色的灵刃擦着她后脑掠过，削断了几缕头发。空气里多了一股焦味。

“跑啊，继续跑！我倒要看看，一个连灵兽都保护不了的废物，能跑到哪里去！”

追兵的声音近了。林静听见他们的脚步声，夹杂着灵能催动的嗡嗡声，像一群野蜂。有人从侧面抄了上来，是个瘦高的男人，手里捏着一团旋转的风灵能，青光照亮他半张脸，笑容扭曲。

“把东西交出来，林静。不然你这条白狗，今晚就变成荒原上的一摊烂肉。”

他说话时，风灵能已经脱手而出。伽玛猛地一个急转，林静整个身体被甩向一侧，差点摔下去。可那道风刃还是擦过了伽玛的左后腿。伽玛喉咙里滚出一声极低的呜咽，脚步踉跄了一下，速度骤然慢下来。

更多的追兵围了上来。青光、红光、白焰，各色灵能在黑暗中亮起，像一圈绞索，缓缓收紧。林静终于看清了他们——五个人，穿着统一的灰袍，领口绣着狰狞的兽纹。为首的是个光头男人，眼神阴鸷，手里没有灵能光，只是背着手，像在看一场已经结束的狩猎。

“林静，”光头男人开口，声音不高，却清晰地穿透风声，“你骑着一条狗，在荒原上跑了半夜，不累吗？”

周围响起低低的嘲笑。

林静喘着气，从伽玛背上滑下来。她站不稳，膝盖一软，半跪在地上。伽玛立刻转过身，用身体挡在她面前。它的左后腿在流血，暗红的液体顺着白色的毛往下淌，在脚边积成一小滩。它的耳朵向后压着，尾巴没有夹，只是低垂，喉咙里发出低沉的呼噜声。

“伽玛……”林静伸出手，摸到它温热的身体。它在发抖。

光头男人走上前一步，目光落在伽玛身上，像在评估一件货物。“这头灵兽……倒是不错。可惜跟错了主人。交出那件东西，我可以留它一条命。”

“不在我身上。”林静说。她的声音嘶哑，像砂纸磨过喉咙。

“嘴硬。”光头男人叹了口气，朝身旁的人使了个眼色。那个瘦高男人立刻抬手，风灵能再次凝聚，比之前更亮，更急，像一柄青色的刀。

“再问一次，东西呢？”

林静没有回答。她只是抱住了伽玛的脖子。那一刻，她的额头抵在伽玛的侧颈上，能感觉到它血管里血液奔涌，像地下深处的暗河。伽玛也偏过头，用鼻尖蹭了蹭她的耳廓。它那双深褐色的眼睛在黑暗里看着她，安静，温顺，像过去无数个夜晚一样。

可下一秒，风刃到了。

林静看见光。青白色的光，像一片薄薄的月亮碎片，朝她们劈来。她闭上眼睛，把脸埋进伽玛的毛发里。

然后她听见了碎裂声。

不是她被击中。是身体里有什么东西碎了。

那声音无法形容，像一道玻璃墙在灵魂深处裂开，灵能从裂缝里喷涌而出。她的心脏猛地一缩，像被一只无形的手攥住，接着又猛地放开。血液冲进四肢，指尖发麻。她感到一股不属于自己的灼热从胸口窜向手臂，窜向伽玛的皮肤。

伽玛仰起头，发出一声低沉的嚎叫。

那嚎叫像从远古荒原深处传来，震得地面都在微微颤动。林静睁开眼，看见伽玛的身体在发光——先是淡淡的银白，然后迅速转浓，像月光凝成了实体。它的骨骼在光中变形、伸展，肩胛处隆起的肌肉剧烈蠕动。林静几乎以为它要死了，可那呜咽渐渐变成了另一种声音，低沉、威严，像沉睡的巨兽翻了个身。

“怎么回事……”瘦高男人后退了两步，风刃已经脱手，却在半空中被某种看不见的力量绞碎，化作点点青光消散。

光头男人脸色变了。他第一次显出动容，低喝道：“别废话，一起上！”

五道灵能光同时亮起，从四面八方朝她们轰来。

伽玛猛地弓起背。林静被一股温柔的力量托起，重新落到它的背上。这一次，她感觉伽玛的身体大了一圈，肌肉结实得像铁铸。它的四足深深陷入泥土，猛地一蹬。

巨大的翅膀从它肩胛处轰然展开，洁白如雪，每一根羽毛都流淌着银色的光。那翅膀展开的瞬间，掀起的风压将最近的敌人掀翻在地。伽玛腾空而起，黑暗的荒原在脚下急速缩小。

夜空里，不知何时出现了一轮圆月。

那月亮大得不正常，边缘泛着一层妖异的暗红，像一只半阖的眼睛，冷冷地悬在荒原之上。月光不是白色的，而是银中带红，像薄薄的雾，无声地洒下来。

林静伏在伽玛背上，仰头望着那轮月亮。她从未见过这样的月亮。月亮的光落在伽玛的翅膀上，每一根羽毛都亮得像刀刃。

伽玛俯冲而下。

它的速度太快了，林静只能紧紧抓住它的毛发，闭上眼睛又睁开。她看见伽玛张开嘴，月光在它口中凝聚成一颗银红色的光球，然后轰然吐出。光球砸在荒原上，没有爆炸声，只有一道无声的冲击波，像水面上的涟漪，瞬间扩散开来。月光落在那些灰袍人身上，像无数细小的刀刃，割开皮肉、骨骼。他们的惨叫只发出半声，便被银红色的光吞没。

荒原上瞬间安静了。

只有风声，和伽玛沉重的呼吸。

林静低头看去。地面上的草石被掀翻，像被巨大的犁犁过，留下一道道深深的沟壑。那些灰袍人已经不见了，只剩下几片焦黑的衣角，像死去的蝴蝶一样落在石缝里。

伽玛缓缓落回地面。它的翅膀收拢，重新贴伏在身体两侧，却并没有消失。体型也没有变回原来的大小，依然是一头比马还要高大的白色巨狼。它转过身，用鼻尖轻轻碰了碰林静的手。

林静跪坐在地上，愣愣地看着它。月光从它身后照过来，在它白色的毛发上镶了一层银边。它的眼睛不再是温顺的深褐色，而是变成了一种极淡的金色，像融化的琥珀，里面倒映着那轮妖异的圆月。

“伽玛……”她哑着嗓子喊了一声。

伽玛低下头，和过去一样，用湿漉漉的鼻尖蹭了蹭她的脸颊。它的呼吸温热，带着荒原上干燥的风和月光的气息。林静张开嘴，想说什么，却发现喉咙像是被什么哽住了。她终于明白，这只一直以为的白狗，原来是头能在夜空下展开双翼的狼。

月亮依旧悬在头顶，冷冷地照着这片沉默的荒原。远处，天边已经泛起一线极淡的灰白。林静把脸埋进伽玛柔软的颈毛里，声音轻得像要散在风里。

“我们回家。”

伽玛低低地应了一声，像一声温柔的呜咽，又像一声初生的狼嚎。
