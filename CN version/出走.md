# 出走

他是一个大贵族子弟，然而他厌倦了这样的生活，想去开创自己的生活，于是在与父母吵架后离家出走，自己创造了一个事业，他有野心有能力也有毅力。但是他曾经觉醒过，曾经帮助过很多人。但是他最后又变成了恶龙，因为他的阶级出身是那样，他没有多少宿慧，他的基因决定了他的思想最终回归，因为他是一个富足靠别人生活的贵族，所以他终究不可能真正对底层感同身受。
这与婆罗门出身的悉达多不一样，因为婆罗门虽然是奴隶主阶级但是仍然有思考甚至有苦行传统，因此理论上里面可能出现一个反叛者。但是其它的可没有，你要相信历史的惯性，一个大贵族下成长的如果没有经历大的变故也没有底层的基因没有底层的环境，即使他再怎么善良再怎么有同理心也不可能真正同情底层的。
