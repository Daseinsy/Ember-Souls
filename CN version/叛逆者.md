# 叛逆者

狂人为了毁灭这个世界，进行了非常周密的计划，外表上看，他是一个强大有地位待人温和的灵修士。但实际上，他暗地里计划了长达十年的毁灭世界冲动，目的不是为了自己，而是拉着这个世界的生灵一起陪葬，他认为死亡就不会再有争斗，不会再有那些令人作呕的伪善者，不会再有那些人为的苦难，不会再有那些可憎的胜利者编写的轮回，如果这个世界已经无可救药的腐朽，那唯一能拯救这一切的只有毁灭。

神国有个反叛者组织，教义是毁灭全世界，但是其掌控者却有部分是想取而代之。

叛逆组织最终被镇压了，但是却在神国内部撕裂出了一道不可忽视的伤口，那道伤口本就存在，只是变得更大更深了，而且神国为了镇压最终牺牲了一个地区的人，没人敢提起那种事情。

其中部分光辉的人在行行现场发出了呐喊，虽然很快就被禁声，但是仍然没有被忘记。
