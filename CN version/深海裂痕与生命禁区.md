# 深海裂痕与生命禁区

无尽之海的中央有一道横贯大洋的漆黑裂隙，如同巨剑劈开的伤口。传说这是诸神黄昏时某位神明陨落时指甲刮出的伤痕——那位神明在垂死之际试图抓住什么东西，指甲划过大地，划出了这道永远无法愈合的裂痕。

裂痕之下的区域被称为深渊，是现象界最接近镜界的地方。深渊中魔物奇形怪状——有千足如蜈蚣的海蛇，有生着人面的章鱼，有透明的巨鲸吞下整支船队后在深海中缓慢消化。这些魔物的体内含有高浓度的邪灵之力，它们的存在本身就在污染周围的海水。海洋因此成了禁区，渔民只敢在近岸处撒网，口中念着祖传的咒语。但总有些亡命之徒驾着小舟划向裂痕——据说有人看见裂痕深处有光，不是魔物的磷光，而是某种洁净的、节律性的光辉，如同心跳。

那是一颗还在跳动的神明心脏吗？还是诸神黄昏遗落的某件神器？没有人知道。去过的人没有回来过，回来的人已经不再是“人”。

生命禁区是陆地上的深渊。腐朽之日诞生的那些禁区，每一处都埋葬着数以万计的生灵。那里的土地是黑色的，空气中弥漫着腐败的甜味，任何活物进入都会感受到灵能急速流失，仿佛大地本身在吞噬你。禁区内盘踞着寂灭级邪灵——它们是邪灵中的王者，拥有相当于人类主宰境巅峰的力量，甚至更强。

为什么生命禁区没有继续扩大？因为英灵。那些在腐朽之日牺牲的人，以献祭的方式化为了土地上的亡魂。他们放弃了轮回，放弃了安息，以魂灵的形态沉睡在大地之下，用庞大的愿力压制邪灵。英灵的存在是一种沉默的代价——他们不再能说话、不再能思考、不再拥有自我意识，只是纯粹的能量屏障。但他们依然在守护。

每一块界碑上至少都刻着一个悲剧。

边境的灵能长城是人类抵御邪魔入侵的最前线。长城由灵能浇筑而成，日夜不息地汲取着边境地区的玛纳维持运转。长城上每隔数里设有一座烽火台，台上的守军全是志愿兵——他们知道自己在最前线，知道邪魔一旦大规模入侵自己必死无疑，但他们仍然站在那里。不是因为勇敢，而是因为背后有家人、有土地、有不该被邪魔践踏的一切。为众人抱薪者，绝不可使其冻毙于风雪之中。

然而邪灵和邪神终究是杀不完的。只要有生灵存在的地方就有争端和恶念，有恶念的地方就会滋生出邪灵。人们倾尽全力修筑长城、培养修士、清剿海洋，不过是在延缓不可避免的结局。这不是一个关于胜利的故事，而是一个关于在注定失败的战争中仍然选择战斗的故事。

人之子最可爱的地方，就是永远有那些幼稚的、相信光的大人存在。他们拼尽全力、不折手段地成为了神灵，想要以此拯救世界，却发现尽头是成为无情的天道。在成为道之前，他们分离出了自己最后的善念，令其化成灵降生于人间。因为是天道的部分化身，灵魂具有不朽的特质——不会消亡，并且能无限转生、保留记忆。这是天道给这个世界留下的最后一份仁慈。尽管祂冷眼旁观，祂甚至可能已经失去了所有的情感，但在成为天道之前的那个“人”，在彻底消散之前，留下了那颗种子。那些种子散落在人间，有时是那个在街头发呆的孩子，有时是那个在战争中保护弱者的士兵，有时是那个在荒野中迷路却仍然向前走的旅人。你不知道他们是谁——他们自己也不知道自己是谁。但当世界真的需要一缕光的时候，他们会想起来。
