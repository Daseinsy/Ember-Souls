# 出走
%
他是一个大贵族子弟，然而他厌倦了这样的生活，想去开创自己的生活，于是在与父母吵架后离家出走，自己创造了一个事业，他有野心有能力也有毅力。但是他曾经觉醒过，曾经帮助过很多人。但是他最后又变成了恶龙，因为他的阶级出身是那样，他没有多少宿慧，他的基因决定了他的思想最终回归，因为他是一个富足靠别人生活的贵族，所以他终究不可能真正对底层感同身受。
这与婆罗门出身的悉达多不一样，因为婆罗门虽然是奴隶主阶级但是仍然有思考甚至有苦行传统，因此理论上里面可能出现一个反叛者。但是其它的可没有，你要相信历史的惯性，一个大贵族下成长的如果没有经历大的变故也没有底层的基因没有底层的环境，即使他再怎么善良再怎么有同理心也不可能真正同情底层的。
%

酒盏摔在大理石地面上的声音，比他预想的要清脆。

碎片四溅，一片划过了他母亲裙摆上绣着的金线凤凰。父亲坐在主位上没有动，只是手指在扶手上轻轻叩了三下。那是他从小听到大的暗号，意思是“到此为止”。但今天，他不想到此为止。

“我要走。”

他说。声音比他预想的要稳。

父亲终于抬起眼。那双眼睛和他一模一样，琥珀色的瞳孔，眼尾微微上挑，看人的时候像在审视一件器皿——值不值钱，成色如何，放在哪个架子上合适。此刻那双眼睛看着他，像在看一件终于决定要自我毁灭的收藏品。

“你走了，这个家的一切就与你无关。”

“我知道。”

“你那些朋友，那些宴会，那些——”父亲顿了顿，似乎在寻找一个精准的词汇，“你习以为常的东西。”

“我本来就不想要那些。”

父亲笑了。那笑容里有某种让他脊背发凉的东西，一种笃定，一种近乎悲悯的确信。

“去吧。”父亲说，挥了挥手，像拂去案上的一粒灰，“让外面教教你，你到底是什么做的。”

他转身走出厅堂，靴跟在大理石上叩出急促的节奏。他没有回头。他知道母亲在身后看着他，但他没有回头。

离开家族领地的那天，他什么也没带。几件换洗衣裳，一把防身的短刀，口袋里几枚灵币。他刻意没有动用家族灵石账户里的钱，那里面存着他从出生起积累的、他都不知道有多少的零花钱。他只要自己挣的。

他的第一个落脚点是一座边境小镇，离城邦的庇护范围刚好差了半日程。这里没有贤者之路，没有灵灯，夜里只能自己点灯。他在一家铁匠铺找了份工，打铁，淬火，拉风箱。火星溅在手臂上，他咬着牙没叫。铁匠是个沉默的中年人，一只手少了三根手指，据说是早年荒野战留下的。铁匠从不多问他的来历，只是偶尔在他打出的铁器歪了时，用那只残缺的手拍拍他的肩，然后示范一次。他学得很快。他从小就被教导要快，快学，快做，快出成果。所以他十天就能打出像样的铁钉，一个月就能打出一把完整的短刀。

后来他离开了铁匠铺，去了更远的地方。他在荒野边缘做过商队的护卫，在城邦之间的荒道上押运灵材，和一些散修同吃同住，喝同一壶浊酒，睡同一片星空。他发现自己确实有一副好身板，灵修士的底子在，那些别人要苦练数月才能掌握的灵能技巧，他几天就能悟透。他帮商队驱赶过邪灵，替落难的散修出过头，甚至有一次，他从一个邪修手中救下了一整支被劫的商队。那个商队的负责人跪在地上给他磕头，他扶起对方，说，不必。

那时候他是真心的。真心觉得自己和他们一样，真心觉得自己离开了那个阶级的桎梏，真心相信人和人之间可以没有那层看不见的壁垒。

他记得有一个晚上，护卫队扎营在荒野边缘。篝火旁坐了一圈人，有老有少，有男有女，都是些在城邦和荒野之间讨生活的底层灵修士。一个满脸风霜的老头一边用残缺的牙齿啃着干粮，一边说起自己的孙子。“那孩子有灵根，测出来是甲等，城邦的学院说可以收，但要交五十块灵晶的束脩。”老头咳了两声，“我攒了三年，还差十二块。明年，明年应该就够了。”

他在一旁听着，心里涌起一股热流。他记得自己当时想：如果是我，五十块灵晶算什么呢。于是他站起来，装作不经意地说，我手上有些闲钱，可以先借你。

老头摇头，其他人也摇头。有人笑了，带着某种他读不懂的意味。

“小伙子，你有这份心是好的。”一个中年女人说，她是个走商的，身上挂着大大小小十几个荷包，“但你不知道，五十块灵晶对有些人来说，是一辈子的积蓄。你今天借了，明天呢？后天呢？”

“我可以——”

“你可以帮一个人。”女人打断他，目光平静而透彻，“你帮不了所有人。而且——”她顿了顿，用火钳拨了拨篝火，火星飞溅，“你迟早要回去的。你和我们不是一路人。”

他当时觉得受到了冒犯。他觉得自己被看轻了，被误解了，被一种他嗤之以鼻的阶级论调框住了。他反驳，他争辩，他举出自己的例子——我不靠家里，我自己挣钱，我和你们吃一样的饭睡一样的地，我怎么就不是一路人了？

女人没有和他争。她只是笑笑，继续拨火。

很久以后，他才明白那个笑容的含义。

他的事业是从一支小队开始的。他在荒野边缘救下的那些散修，有几个愿意跟着他干。他有灵修士的实力，有头脑，有家族培养出来的眼界和决断力，还有某种天生的领袖气质——那种从小在宴会和议事厅里耳濡目染出来的从容，那种知道如何让人信服、如何让不同的人各得其所的本能。他的小队很快在荒野边缘闯出了名号。他们接委托，清剿邪灵，护送商队，探索遗迹。他给队员开的报酬比市面上高两成，还包吃住，受伤了他出灵石请人治，死了人他亲自上门送抚恤金。他的队员越来越多，从三五人变成了几十人，又变成了上百人。他的名字开始在荒野边缘流传。

一切似乎都在证明他是对的。他可以离开那个阶级，他可以创造自己的世界，他可以和底层人真正地站在一起。

转折点来得比他预想的要早。

那年冬天，荒野边缘爆发了一场大规模的邪灵潮。源头据说是某个古代遗迹被意外开启，大量沉睡的邪灵涌出，吞噬了沿途的村庄和商道。他的驻地在邪灵潮的波及范围内。他带着队伍撤到了一个叫灰石岭的高地，那里地势易守难攻，有天然灵脉可以依托。高地附近还有几个小村庄，住着几百户人家。那些村民没有灵修士，面对邪灵连还手的余地都没有。他们的村长来找他，跪在地上求他带人保护他们。

他看着那个跪在地上的老人，穿着打满补丁的粗麻衣裳，双手粗糙得像树皮，额头磕在冰冷的石头上。他认识这样的手，他在铁匠铺里见过，在商队护卫的营地里握过。他应该答应的。他想答应。

但他的副手，一个跟他出生入死多年的老散修，把他拉到一边，低声说：“头儿，咱们的灵石储备只够维持高地的灵脉屏障三天。三天后如果援军不到，咱们自己的人都不够用。带上村民，屏障消耗会翻倍，最多撑一天半。”

他愣住了。

他想起自己在城邦家里时，父亲处理政务的方式。父亲面前摆着厚厚的卷宗，每一个卷宗都是一方百姓的生死。父亲总能在片刻间做出决定：救谁，不救谁，谁更重要，谁可以牺牲。父亲做那些决定时，手指在扶手上叩的节奏始终不变。

他当时觉得父亲冷血。

现在他站在灰石岭上，风从荒野深处刮来，带着邪灵的腐臭和远方的哭声。他的手指在身侧无意识地叩了三个节拍。然后他抬起头，看着那个跪在地上的老人。

“我们只能带三天补给。”他说，声音平稳得连他自己都意外，“三天后，无论援军到没到，我们都要撤。你们的人，我只能带三十个。老人、孩子优先。剩下的……”

老人抬起头看他。那双浑浊的眼睛里有一种他太熟悉的东西，那个商队女人曾经有过的平静，那个铁匠沉默的注视，那个荒野篝火旁某个不知名散修的一闪而过的了然。

“我明白了。”老人说，慢慢站起来，膝盖在风中微微发颤，“三十个名额，我来分。”

他转身走了。那身影佝偻着，像一棵被雷劈过的老树，还在勉强立着。

他站在高处看着老人回到村庄，看着村庄里亮起一盏盏昏暗的灯，看着那些光一盏一盏地熄灭。三天后，他带着三十个村民和全部队员撤离了灰石岭。他的决定救了很多人。他的队员一个没少，三十个村民活了下来。他的名声更响了，人们说他果断，理智，有担当。

但他再也没有见过那个老人。

后来他打听到，那个老人把三十个名额全分给了村里的孩子和孕妇，自己留在了灰石岭。邪灵潮退去后，救援队在高地上找到了一些东西。一些碎骨，一些残破的衣物，和一把锈蚀的铁锹。那是老人平时挖地用的。

他听到这个消息时，正在自己的营帐里擦拭短刀。他的手停住了。帐外的篝火噼啪作响，远处有队员的笑闹声，有人在煮汤，肉香混着香料的味道飘进来。他坐在自己的营帐里，铺着三层兽皮褥子，用着一整块玉石雕成的杯盏，里面盛着从城邦运来的灵酒。

他忽然想起，自己有多久没有和队员一起席地而坐喝浊酒了？有多久没有睡在篝火旁了？

他想起那个商队女人说的话。你迟早要回去的。你和我们不是一路人。

他当时以为她说的是出身。

她现在说的其实是——你永远学不会在三十个和三百个之间，选择让三十个去死。而底层的人，他们不需要选择。他们从来只有一条路，所以他们做决定时，心里只有一件事：怎么活下去。

而他做决定时，心里有太多的事。有大局，有进退，有得失，有考量。

他坐在营帐里，手里的短刀映出他自己的脸。琥珀色的眼睛，微挑的眼尾，和他父亲一模一样。

后来他的队伍越来越大，从荒野边缘打进了城邦之间的缝隙，从缝隙里挤进了灵材贸易的主干道。他开商铺，设据点，收保护费，做中间人。他做的事和那些他曾经厌恶的贵族没什么两样，只是他更年轻，更高效，更不像“贵族”。他的队员们开始叫他“头儿”，后来叫“主上”，最后叫“大人”。他一开始还纠正，后来就不纠正了。

再后来，他听说城邦要组建一支新的灵修士军团去平定荒野深处的叛乱。他去了，带着他的队伍，带着他这些年积累的实力。他见到了那些曾经在宴会上一起饮酒的贵族子弟，他们还是那样，玩世不恭，目光短浅，只在乎谁家的剑穗更值钱。但他们的父亲、叔伯、族老坐在军帐里，看他的眼神变了。不再是俯视一个不肖子弟，而是平视一个可以对话的人。他们把他当作同类，因为他确实已经成了同类。

他坐在军帐里，和那些贵族商议战事、分配利益、签订盟约。他说话的方式和他们一模一样，他思考的方式和他们一模一样。他甚至在某个瞬间意识到，自己指叩扶手的节奏，和父亲一模一样。

那天晚上他喝了酒，独自走到荒野边缘。贤者之路在脚下延伸，灵灯在黑暗中摇曳。远处，神国的轮廓在夜空中沉浮，巨大的屏障泛着微光。他想起很多年前，他离开家的那个清晨，母亲在身后看着他，他没有回头。

现在他站在这里，身后跟着一整支军团，上百号人等着他发号施令。他成了他曾经想推翻的那类人。他甚至比他们做得更好，因为他了解底层。他知道怎么让底层人死心塌地地跟着他，知道怎么在最低的成本下榨取最高的忠诚度。他的出身让他比那些纯粹的贵族多了一把钥匙，一把打开底层心门的钥匙。

他掏出腰间的短刀。那是他亲手打的第一把短刀，在铁匠铺里，火星溅了满脸。刀身上有细密的裂纹，因为当时淬火的火候没掌握好。他一直留着它，不知道为什么。

现在他站在荒野边缘，拇指摩挲着刀身上那些裂纹。风从黑暗中吹来，带着硫磺的气息。

远处传来女子的呼救声。救命啊，救命啊，这里有邪灵。

他笑了。

他收起短刀，转身走回军帐。明天还有一场仗要打，那些贵族盟友们等着他一起制定计划。他需要洗个澡，换身衣服，在军营里点上一盏灵灯。他走到帐门口时停了一下，回头看了最后一眼。

黑暗中，贤者之路的灵灯像一串漂浮的珍珠，渐行渐远。更远处，神国的光在静静燃烧。

他忽然想，父亲是对的。

外面确实教会了他，他到底是什么做的。

但他不知道的是，在他看不到的地方，那把被他收起的短刀刀柄上，刻着一行极细极浅的字。那是他离开铁匠铺那天，老铁匠用那只残缺的手，偷偷刻上去的。

字很小，但一笔一划，清清楚楚。

“莫忘来处。”
