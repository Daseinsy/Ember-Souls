# 无声者

人造太阳的光准时从东边亮起来，像一只巨大的、永不眨眼的瞳孔。

阿尘已经醒了。他躺在下铺，听着上铺翻身时铁架发出的呻吟。墙壁很薄，隔壁房间冲马桶的水声从管道里传下来，像是什么东西在暗中呕吐。他的眼睛盯着天花板上那道细长的裂缝，从墙角一直延伸到灯座旁边，像一条干涸的河。

他数过了。一千四百六十二天。

从他被分配到第七福利区的这一天算起，人造太阳亮了一千四百六十二次。每一天都精确得像刻度线，切割着他剩余的生命。他十八岁，身体没有任何疾病。精神评估报告上写着：正常。社会化评分：中等偏下。贡献潜力：待观察。

阿尘坐起身，后脑勺撞到了上铺的床板，闷响。上铺的人翻了个身，没有醒。他弯腰穿鞋，鞋带断了一根，断口毛糙，是上个月就磨破的。他打了个死结，继续穿。

食堂在地下二层。空气里弥漫着合成蛋白和消毒水混合的气味，像一层油膜覆在喉咙口。队伍排得很长，人人都穿着灰色的标准服，从背后看像一列没有面孔的影子。阿尘端着自己的餐盘往前走，今天的配给是一块压缩谷物、一勺蛋白糊、半杯温水。他找了个角落坐下，面对墙壁。

墙壁上有字。

有人用指甲或者别的什么尖东西刻上去的，歪歪斜斜：我想看见真正的太阳。

阿尘看着那行字，勺子停在半空。他认得这行字，上个月它还不在这里。上个月坐这个位置的人被带走了，听说是在夜间宣讲会上突然站起来，大喊了一句什么。阿尘没有亲耳听到那句话，但后来整个福利区都在传：那个人喊的是“天上的那颗是假的”。

神国的守卫反应很快，三秒之内就按倒了他，堵住嘴拖了出去。自那以后，食堂的角落重新粉刷过一遍，现在这行字是新刻的，刻痕很深，指尖摸过去能感觉到粗糙的阻力。

阿尘收回手指，把最后一口蛋白糊咽下去。它尝不出味道，像是嚼着一团温热的泥。

出勤铃响了。

车间的灯光比食堂更亮，亮得没有阴影。阿尘的工作是给流水线上的零件做目视检查，一分钟四十件，误差率不能超过千分之三。他面前的传送带永不停歇，那些银灰色的金属块像一条沉默的河流从他眼底流过。他的手指不需要思考，只有眼睛在动。

旁边工位的林叔偶尔会说话。他是第七福利区的老人了，五十多岁，脸上有一道从眉骨到下颌的旧伤疤，每次转头时伤疤会随着肌肉抽动，像一条蜈蚣在皮肤下爬。

“听说九区那边又死了一个。”林叔的声音压得很低，嘴唇几乎不动，这是他多年养成的习惯。

阿尘没有抬头，眼睛盯着传送带。

“怎么死的？”他问，声音同样低。

“审查。”林叔说，“说他交上去的思想汇报里有一句话用词不准确。关了两天，心脏骤停。”

传送带上的一颗零件表面有细微的划痕，阿尘把它挑出来，放进次品盒。动作干净利落，误差率依然保持在千分之一。

“他家领到补偿了吗？”阿尘问。

“补偿？”林叔的嘴角动了动，“他父母去年就没了。孤身一人。区里连讣告都没发。”

传送带继续流。四十件。四十件。四十件。

中午休息的时候，阿尘没有去食堂。他走到车间外面的走廊尽头，那里有一扇被封死的窗户。他透过玻璃的裂纹往外看，人造太阳悬挂在神国中央，明亮、稳定、没有一丝波动。所有的建筑都笼罩在那片均匀的光里，没有影子被拉长，没有角度在改变。像一张曝光过度的照片，所有的东西都在，但所有东西都显得虚假。

他记得小时候，在福利院最大的那个活动室里，老师给他们放过一段影片。那是大灾变之前的影像记录，来自一个已经不存在的地方。画面里有一轮太阳，从一个叫“地平线”的地方缓缓沉下去，颜色从炽白变成橙黄，再变成血一样的红。那种红蔓延了半个天空，像在烧。

阿尘当时看哭了。

旁边的孩子都笑他。老师拍拍他的头说，没关系，这是正常的情绪反应。

后来他才知道，那个老师第二天就被调走了。理由：在儿童教育过程中展示未经审核的历史影像。

现在他站在封死的窗户前，看着头顶那颗永远不会落下去的人造太阳，眼睛很痛。他知道这种痛是生理性的，和情绪无关。但他隐约希望自己能像小时候那样哭出来。他哭不出来了。

那天夜里，熄灯之后，阿尘躺在黑暗里，听着整栋楼的呼吸声。上铺的人在说梦话，断断续续的，像是在念一段祷告词。阿尘听清了几个字：求求，放我出去。

他翻了个身，面向墙壁。

墙壁上刻着字。昨天没有，今天有了。就刻在他的枕头旁边，那些字像从灰白的墙皮里长出来的，又小又深，每一道刻痕都带着某种近乎疯狂的力道。他凑近了看，只有三行：

不要说话。

我在听。

他们也在听。

阿尘盯着那三行字，感到自己的心跳忽然变得很响，像是有人在胸腔里用拳头敲打一面看不见的鼓。

他没有动。甚至没有伸手去摸那些刻痕。他就那么睁着眼睛，在黑暗中感受自己活着——心脏在跳，肺在呼吸，血液在血管里一圈圈地跑。他感受着这些，也感受着别的：那种从四面八方涌过来的、沉默的、无处安放的恐惧。别人的，自己的，混在一起。

他觉得自己像一根被调紧了弦的琴，任何一点风吹草动都能让他震颤不止。

阿尘想，只要自己能健康的活着，一切就都还有商量的余地。死了，就什么都没了。人生不是独木桥，是场马拉松。短期的领先不算赢，能安安稳稳走到最后才叫赢。可这个世界给他的感觉就像一场醒不来的梦，他跑在这条永无尽头的赛道上，前面没有终点线，身后没有追赶者。只有那颗假太阳，永远挂在天上，照着他，也照着所有人。

他闭上眼睛。

梦里，他看见一颗真正的太阳，正从某个遥远的地平线上沉下去。天空在燃烧。他张了张嘴，想对谁喊一句什么。但梦里没有声音，他也没有嘴巴。他只是一双眼睛，目睹着那场盛大的、被禁止的落日。

醒来时，人造太阳已经亮了。
