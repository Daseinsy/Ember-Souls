# 结局与循环

这个世界没有完美的结局。

反派杀不完，邪灵灭不尽，阶级不会消失，痛苦不会停止。旧的城邦被邪灵攻破，新的城邦在废墟上建立，然后几十年、几百年后，它又会被攻破。所有人在做的事情，本质上都是在延缓一个不可避免的结局。就像西西弗斯推石头，只是推得更用力、更认真、更有仪式感。

但这个世界的核心机制中存在着一个微小的例外——天道善念的化身。那些在成为天道之前分离出来的最后善念，化作灵降生于人间。他们具有灵魂不朽的特质：不会消亡，并能无限转生、保留记忆。在每一世中，他们可能是一个普通的孩子、一个不起眼的士兵、一个在街头发呆的旅人。他们自己也不知道自己是谁，但当世界真的需要一缕光的时候，他们会想起来——想起自己来到这个世界是为了什么。

这些人不会拯救世界。他们只是让这个世界在被毁灭的过程中，多一点点值得被记住的东西。他们做的事可能很小：在战争中保护一个孩子，在瘟疫中照顾一个陌生人，在绝望中说出一句温暖的话。那些事不会改变历史的走向，不会终结邪灵的威胁，不会让阶级分化消失。但它们会在某些人的记忆里留下痕迹——当一个孩子长大后，他会记得自己小时候被一个过路的无面者救过，然后他也会成为那个在别人需要时伸出手的人。这就是传承。

谨以此文，纪念一切逝去。那些已经不在的人，那些还活着但已经被生活磨平了棱角的人，那些在深夜里独自挣扎却仍然没有放弃的人。他们或许终其一生都不会被历史记住，但他们的存在本身，就是文明之所以值得继续的理由。

不要哭，不要哭，希斯。超越一切的向往或许终将消逝于风中，但在它消逝之前，它曾经照亮过一些人。如果这个世界终将走向黄昏，那就在黄昏中点亮一盏灯。灯火不是为了照亮整个世界，而是为了让人知道，即使在最深的黑暗里，仍然有人愿意做那个举着火把的人。

她终于可以休息了。过去的每一分每一秒，都像是在经历几万年的熬煎。但她走过来了，她还在往前走。前方不一定有光，但她自己就是那道光。

如果这世上没有令我怦然心动的作品，我就自己创造一个这样的史诗。首先能够感动自己。但愿我的文字能够给那些黑暗中前行的人们，些许温暖，些许慰藉。愿那些白金般的心灵永不凋零和褪色。

我也是一个讲故事的人。在讲故事的时候，我会感到成就感和前所未有的放松，仿佛我不需要担忧这个世界的白天黑夜、喧嚣吵闹、生存与挣扎——我只需要用故事传递我的灵魂想说的，带给人们温暖、幸运，还有希望。虽然我是一个平凡的人，也背负着自身的业火，但我想留下些东西。人啊，总得燃烧一次，不能在无止境的琐碎生计中逐渐麻木、丧失灵性，乃至于丢失了自己是什么。

我希望这个世界少一些争端，少一些隔阂，少一些杀戮，少一些冷漠。我希望那些读着我的故事的人，能够回归本真，想起人首先是生命，不是身份、不是职位、不是工作、不是学习。不需要成为什么宏大叙事的一部分，你生来就已经足够珍贵了。你所背负的一切都不是罪过，你的存在就是意义本身。

凡是过往，皆为序章。每一个结束都是新的开始，每一盏熄灭的火都曾被另一盏点燃。而只要还有人愿意在黑暗中举起灯火，这个世界就还没有彻底死去。
