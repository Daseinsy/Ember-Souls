# 灵兽

灵兽是一种神奇的生物。传说它们来自所有生命意识都曾驻留过的灵界，拥有超越人体的神奇力量。灵兽因孕育而生，并非原本就存在的生物，没有人知道它们具体是如何诞生的。传说，当邪灵第一次入侵这个世界时，人类的肉体凡胎几乎毫无阻挡之力。就在那时，极其强烈的信念让世界上第一只灵兽诞生于现实。它浑身环绕着火焰，无形无质，一举终结了灵异时代。后世的人们称它为“薪”。

直到现在，每座聚居地都设有“薪”的神殿。神殿中燃烧着神圣的火焰，可以驱散大部分邪异，或降低其发生率。然而，灵兽有可能堕落。灵兽堕落的过程被称作“殇”，其育灵师也因此被称作邪灵师。

余烬在头疼中醒来。他无父无母，据说是爷爷奶奶在荒野中捡到了他，然后抚养长大。他现在体内仿佛拥有无穷无尽的力量，但他决定先看，而不是做。况且，他现在的力量也远没有到真正无可匹敌的程度。心里有个声音在说：力量并不是万能的。即便他直接打杀了最终boss，那又能怎么样呢？

奶奶：“宝宝回来了啊。”

课堂上，老师讲授着，可余烬只感觉昏昏欲睡。所以，他是老师眼中的坏学生。因为他一眼就会了，可又缺乏欲望，也不想去展示。他只是想平静地生活而已。

啊，他就坐在靠窗的位置。午后的阳光洒落下来，一切都是这样的美好啊！

在这个浮躁浮华，乃至于思维方式和认知都被算法和垄断所控制的时代，纯粹的文字反而显得越发珍贵。眼花缭乱的界面在不断进化和变动，但精神内核却越来越显得贫乏和空洞，或者说，并没有什么长进。如果每一个具体的人在资本的收割中，只是多巴胺的傀儡的话。
