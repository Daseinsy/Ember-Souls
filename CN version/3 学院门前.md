# 3 学院门前

广场铺着整块青白色玉石，紧挨学院大门，却尚未真正踏入学院内部。人声从四面八方涌来——孩童的嬉闹、家长的叮咛、灵兽振翅时羽毛摩擦的沙沙声，混成一片嗡嗡的低响。

“听说有天赋的人，都是被神灵选中的。”大小姐身旁一个锦衣华服的青年——正是她的兄长——目光复杂地望向她们，低声感叹道，“可什么是天赋？灵性这东西，测不出来，也量不出来。最后也只能拿灵能境界，粗糙地衡量一个孩子的潜力。”

那青年声音逐渐变得幽怨：“我整天泡在内城的图书馆里，每天让能请到的最好的灵修士对我进行辅导，然而却让老妹先我一步。”

“哎，老哥，你能不能别抱怨了，酸死我了。”大小姐狠狠戳了戳他的腰。

远处飘来熟悉的雪松清香，是雪见不知何时已走到近旁，望着远处那扇紧闭的金色大门，柔声道：“可也总有大器晚成的。”林静不需要回头也知道那是她——那种清冷而干净的气息，几乎是他在这座陌生城池里唯一能辨得出的“熟悉”。

青年怔了一下。“有人甚至在几十岁甚至暮年才悟入‘初心境’，”雪见的声音很轻，像在对自己说，“随后在‘登神长阶’上一路疾行。”青年摸了摸头，苦笑一声：“是啊，但是那是天命者的宿命啊。”

高空中，几名学院执事模样的青年骑着状似雄鹰的灵兽，无声地掠过广场，目光沉稳而锐利。

林静感受着四周涌动的灵光，望向那些从前闻所未闻的新奇事物。远处，巨大的学院轮廓隐约可见，仿佛沉浮在星河之中。身边，部分上位者身后侍奉着半透明的灵仆，轮廓如水墨晕开的人形，动作轻柔而体贴，递茶时连杯沿的朝向都精准无误；而不远处，几个制式化的灵偶正机械地搬运着行李，金属关节发出细密的咔嗒声，面容都是同一副标准的平和微笑，像同一个模子印出来的沉默仆人。

一位面容秀美的单亲妈妈牵着一个小女孩。二人衣着朴素，与周围那些内城的贵人形成鲜明对比。因孩子年龄过小，母亲按特殊管理条例得以进入神国内区陪读，但仍不被允许进入学院内部。

旁边其他家长柔声问道：“小姑娘今年多大了？”小女孩怯生生地回答：“我今年九岁了。”周围人感叹：“九岁就能来学院，这孩子前途不可限量啊。”

——林静注意到，部分观众嘴角微微一斜，随即迅速敛去，只露出文质彬彬的微笑。他们似乎想起很多年少成名最后泯然众人的例子，灵能境界只是当下的成绩，但人生是场马拉松，不是个短跑竞赛。

林静孤零零站在喧嚣的人群里，连身边的空气都隐隐透着一丝凉意。他抬手碰了碰自己左胸的位置，那里空空荡荡的——说不清是少了什么东西，还是从来就没有过。周围的孩子都有大人牵着，而他只有自己。

小女孩不去别人身边，反而怯怯地走到他身旁，说：“哥哥，你这边好凉快啊。”她的眼睛干净得像被水洗过无数遍。林静微微一怔，低头看她，嘴角动了动，像是不知该如何回应。他从不知道站在自己身边会让人觉得凉快。他下意识看了看自己的手背，没什么异样，那句童言却像一颗小石子投进深井，落下去没听见回响，只觉得一直往下沉。他随后道：“或许因为这里人少些。”

此时，清晨雨露未散，金碧辉煌的穹顶泛着琉璃色，神圣的光从高处落下。

一道威严而温和的声音响起：“大家不必紧张，下面是洗礼流程。”

紧接着，地上浮现巨大法阵，法阵亮起的瞬间，淡金色的光点如萤火虫群从地砖缝隙中浮起，缓缓旋转着上升，像无数双温柔的手托住每个人的脚踝。林静只觉脚底一轻，整个人像踩在一层凝而不散的水面上，耳朵里响起极轻的嗡鸣，像远处有人在哼一支没有词的调子，胸口那团压着的什么便在这声音里无声地松开了，身体的沉滞仿佛化作雨后的露水，缓缓蒸发。

随后天上落下光点，每位孩子胸前的身份铭牌开始同步发光。那铭牌是每个公民自幼便有的身份凭证，与每个人独一无二的灵性印记相绑定，无法仿冒。林静低头看了一眼自己那块——灰扑扑的铁色，上面刻着一串他早已背得烂熟的数字，但他总觉得那串数字像贴在他皮肤上的标签，属于他，又不完全是他。他伸手碰了碰，铭牌微微发烫，像在被什么确认着身份。

人群中，几个华服妇人聚在一起，周围侍立着神情锐利的灵偶，一边惬意地舒展着微微发福的身体，一边议论着谁家孩子灵光更纯净。

这时，每个孩子脑中自然浮现出学院生活的规则与注意事项，以及自己对应的生活场地。那是一张记忆的蓝图，即使无法立刻吸收，用到时也可回忆。

人群按照指示，开始慢慢向前移动，像一条缓慢流淌的河。

法阵中央的金色光晕逐渐收拢，就在这时，空气里的光色忽然从金黄褪成惨白，暖意像是被人掐住了喉咙，猛地一滞，像是被什么从外侧撕开一道细缝。

林静刚跟着走出两步，一股腐木般的凉意忽然从脚底蹿上脊背，耳边的嘈杂人声也像隔了一层水，忽然变得遥远而模糊。他下意识停了脚步，几乎在同一瞬间，一道扭曲的黑影从突然冒出的虚空裂隙中挤了出来，带着腐败的腥气，径直扑向他所在的方向。

尖叫声像被扯裂的布帛一样炸开，周围的人群顿时乱作一团。她母亲就在几步之外，正低头整理行囊。黑影来得太快，林静只来得及侧过身，用肩膀将那个之前站在他旁边的小姑娘往她母亲的方向拦了一下。

但黑影刚一现身，便被数道强大气息锁定，像被钉在空气中的虫子般猛地僵住；附近的执事只是轻轻一挥手，黑影已被压制在地，随即多道金色锁链自高空探出，将其熔作飞灰。

广场上安静了几秒，连灵兽扇动翅膀的声音都停了。这时才有人后知后觉地反应过来，大呼道：“邪灵——是邪灵入侵了。”“这里可是学院门口，怎么还会有邪灵敢冒出来？”

“不必惊慌。”那道威严而温和的声音再次响起，带着一种说不清道不明的安抚之力，令人不自觉的放松下来。

学院内部的管理者透过天眼将一切尽收眼底，低声道：“这说明不止一个灵性强大的孩子受到邪灵觊觎。”片刻后，有人低声汇报：“所有学生身上均未沾染邪气，可以放行。”

再没有多余的套话。金色的学院大门轰然向两侧展开，像雄鹰张开羽翼，空气中荡起无形的气浪。孩子们只觉被漩涡般的气流锁定，身后像有一双看不见的大手，托着他们向门内飞去。周围的家属停在原地，学院作为圣地，不容外人随意进入。

华服青年对自己的妹妹有气无力地挥了挥手，脸上浮着薄薄一层艳羡之色。

半空中的小女孩回头望向妈妈，眼里闪着泪光：“我会想家，想妈妈。”妈妈停在原地，向她伸出双臂，似乎喊了些什么，眼里有不舍，有坚定，还有被泪光洗过的希望。

林静落在最后，回头望了一眼广场上星星点点的人群，又看了看自己身侧。方才小女孩靠近时那一丝暖意，似乎还缠在他袖口，若有若无。他说不清那是小女孩留下的，还是从自己身体深处渗出来的。

他收回目光，四肢像婴儿安睡时那样蜷曲着，任凭那束牵引的风将他卷入门内。暗金色的辉光中，远处神殿的巨大轮廓若隐若现，那位几乎从不露面的神灵，依旧在那里，保持着最大限度的神秘。
