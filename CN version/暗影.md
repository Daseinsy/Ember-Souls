# 暗影

无心一直知道自己的身边总有一个暗影，那个影子叫做我。
无论他做什么想什么，最终的一切都会像回旋镖一样回转到我，无心的我很争强好胜，他总是有一种紧迫感想要超越胜出，幸运的是他有对应的部分能力，但是他觉得自己不快乐。
巨大的銀灰色巨門，門上雕刻著巨大的天使羽翼圖案。一張面無表情的嚴肅的臉。
眼部識別通過，身分卡識別通過，指紋識別通過。
浮現一張巨大的笑臉，羽翼伸開，大門緩緩張開。
走到連廊，門內正好出來書記小王，门开的一瞬，仿佛有什么隐隐绰绰的声音从房间内传出，親切的打照護，走过他时小声说了一句，进去轻点哦。
这里有个任务，需要你作为助手。
高高的院长办公室，古老的東方檀木的香氣，巨大的神灵辉印雕刻在正中央，顶部洞开，洒下朦胧的光点。
周围灵力刹那间提升了好几倍，整个毛孔仿佛都在舒展。
院長背對著他，仰靠在宽阔的躺椅上，桌子上放着一个水晶球，里面正放着音乐。
貌似是某个歌星的歌，几十年前的歌了，无心曾经听过。
旋轉回來，雙手合攏于腹部，周身散发着气场，身旁两位黑武士雕塑手持利刃伫立在角落，一头金眸羽翼的灵兽闭眼趴在那。
无心不敢出声，只是静静的等待着。
神情恭敬的弯腰抚胸，问好。
至于任务的内容是，院长一抬手向他打来秘语。
签署完这份文件，你以前干的不错，这次也一样。
无心回到自己的家，家里空空如也，没有一个人，甚至连人类仆从也没有，只有孤零零的灵偶在他进来后得到指令开始运转。
薪火在壁炉里点燃，热腾腾的饭菜被端上来。
餐桌旁总有几张空着的椅子，上面摆放着破布的娃娃。
无心躺在床上，思绪万千，嘴里哼着韵律不明的小区，但是逐渐变得诡异，发出嘻嘻压抑的笑声，又好像孩童压抑的哭泣，他在梦中又哭又笑，表情不断变幻，神情癫狂。
