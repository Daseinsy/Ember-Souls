# 诸神黄昏

圈养场，不清楚命运和意义的牛羊，仿佛无所不能的天罚巨手，被迷雾笼罩的小镇，出去回来后不自然的人类，被不断汲取的灵，一代又一代的人类，被安排好的命运，伪人，可爱的人们，阳光从云层中照下，歇斯底里的，遗忘症，所谓圣女。领主拥有的世界，领主生活的世界，领主生活的世界的领主，死寂，绝望，认知瘴，觉醒者，异教徒，没有结局的游戏，没有新事，被欲望和权力支配的历史，重复的厮杀，命运的游戏。一个终极领主的唯一掌上明珠，因悲悯选择失去记忆下入人间，她拥有无限的生命，但除此之外她一无所有，领主不会选择帮助她，因为祂觉得NPC对女儿造成的伤害都是虚幻，祂没有性别，因为祂是神，祂不具有正常人的感情，因为祂是神，因为祂能直接抹去因果，祂只希望唯一的女儿能够经历轮回得吾大道并最终登临神位，祂不是独裁者也没有欲望，祂是一切的终极之一，祂是天道的化身，祂只会冷漠的注视着一切，她只会一次又一次的轮回，每一次死去领主都会洗去所有人关于她的记忆，下放入下一次轮回，直至她意志上放弃情感为止。她不知道她是谁，她叫什么名字，她来自何方，她的心中有一团火，她不知道那团火是什么，然而在生的过程中，她逐渐知道了那种说不清道不明的东西是什么。她有一头天火红的长发，和一双黑夜般渊深的眼眸。
每一个生物都有属于自己的灵，那些灵都是独一无二的。传说每个生物死去的时候，他们的灵会飞上天空，升入冥界，汇入冥河之中，冥河其实有两段，前段才是冥河，后端则是生者之河又叫时间长河，两条河平行而出，然而从未交汇，人们不知它们起于何处流向何方。传说天上的每一颗星星都是死去的灵，地上的人们只要诚心祈祷，就能与星星产生感应，然而对应的星星就会虚化消失。不同领主的拥有世界之间仿佛隔着无尽的迷雾。领主当然能下凡，但是人们看不见祂，就像纸上画的蝼蚁永远也不会抬头看见天空。人们会将各种领主造成的自然灾害，解释为神灵发怒，然而为此祈祷贡献灵。
主宰能抹去时间，抹去空间，抹去因果，抹去一个灵存在过的任何痕迹，连时间长河都是一件玩具，祂们本就超脱于时间，在它们眼中没有时间只有一系列记录，就像程序一样，程序可以运行但也可以被记录被备份，可以随时被停止删除复原加速跳过修改，主宰们当然也有自己的时间，只不过它们的时间和人之子们的时间完全不是一回事。
她会失去，然而她的每一次转生都会保留她的所有记忆和灵。
她仿佛看到了一整片星空，其中的每一个光亮都是一个世界，她说不清到底有多少颗星星，因为她置身于一整片星海之中。越来越大，越来越大，然后是一个越来越大，迎面撞来的世界。
这是一部悠久的史诗，因为它试图刻画世界。你可能会对无尽的轮回感到厌倦，但是你总能找到一个新奇的世界，但是悠久的时间又会让你无穷尽的开始厌烦贫乏，直到她开始使用自杀的手段来轮回世界为止。然而每一次轮回都会来到新的世界，然后被赋予新的身份，但她永远也找不到回去的路，所有的遗憾都无法弥补，所有的一切都是过去。领主可以静止时间加快时间，但是不能让时间倒流。时间倒流要逆流而上，然而那要对抗整个时间长河的冲击，所需耗费的灵哪怕以亿为单位记录也只能使一个领主世界倒流几秒，时间回溯那是只属于神的权柄。然而没有绝对的时间，每个世界的时间都是不同的，它们只是开始一个起点然后流转下去。
只是有一个叫时空门的东西，能够将不同的世界连接起来，其中的生物可以通过此门来到别的世界。
然而她的灵仿佛星核一样坚不可摧，甚至无法被撼动，因此即使在时间长河的冲刷下它也从不磨损只会历久弥新她的容颜从不会老去，只是会变化，会变得更沉淀更成熟，只有自己的心灵能使她变老，然而她的心灵仿佛从未老去。
她能选择无限转生到当前世界，但是她总不能在一个世界无限停留，因为世界的寿命也是有限的，领主会衰老世界会枯竭世界会枯败，每一个世界最终都会走向毁灭，当灵干涸的时候，世界就会土崩瓦解，散成无数光点归于星空。
认知瘴就是，即使主宰者静止时间，其中世界的生物也不会察觉到时间曾经停止过。百年孤独，千年孤寂，一瞬沉沦。人类饲养家畜，然而谁又在饲养人类。
看着眼前的荒芜，复杂，哭的，笑的愤怒的，那些不同的熟悉的脸庞仿佛缠绵成了无可分割的影像，像一颗巨大的光怪陆离的眼珠，倒映着这世间的所有景象，他想起前世的一首歌。
